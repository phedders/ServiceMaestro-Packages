Debian / Ubuntu

Server and CLI packages for amd64.

echo "deb [trusted=yes] https://phedders.github.io/ServiceMaestro-Packages/apt ./" | sudo tee /etc/apt/sources.list.d/service-maestro.list
sudo apt update
sudo apt install service-maestro-server
# optional command-line client
sudo apt install service-maestro-cli

Fedora / RHEL / Rocky

Server package for x86_64.

sudo tee /etc/yum.repos.d/service-maestro.repo >/dev/null <<'EOF'
[service-maestro]
name=Service Maestro
baseurl=https://phedders.github.io/ServiceMaestro-Packages/rpm/
enabled=1
gpgcheck=0
EOF
sudo dnf install service-maestro-server

About

Packages are rebuilt from the latest public Service Maestro release. Source RPMs, desktop builds and other release assets remain on the release page.

These repositories are currently unsigned. The APT command uses [trusted=yes] and the DNF repository uses gpgcheck=0. If you need signature verification, download the release assets directly and verify them against the release checksums.

Repository source and build workflow: phedders/ServiceMaestro-Packages.
